# Miniguia de Estudos: Beabá dos Investimentos com NotebookLM 🚀

## 📝 Contexto e Objetivos
Este repositório foi criado para o desafio da DIO sobre Aprendizagem Ativa. O foco aqui é o **"Beabá dos Investimentos"**, transformando conteúdos densos de vídeos em um guia de estudo estruturado através do NotebookLM.

**Objetivos de Estudo:**
* Entender os primeiros passos para sair da poupança.
* Compreender o papel da Taxa Selic na rentabilidade.
* Aprender a estruturar uma Reserva de Emergência com segurança e liquidez.

## 🧠 Engenharia de Prompts e "Cicatrizes"
Durante o uso do NotebookLM, testei diferentes abordagens para extrair o melhor das transcrições:

| Intenção | Prompt Utilizado | Resultado/Ajuste |
| :--- | :--- | :--- |
| **Resumo** | "Liste os 3 principais ativos citados nos vídeos para quem tem perfil conservador." | A IA trouxe os nomes, mas precisei pedir para incluir o 'porquê' de cada um. |
| **Comparação** | "Crie uma tabela comparando Tesouro Selic e Poupança baseada apenas nos vídeos." | Ótimo resultado para visualizar a perda de poder de compra na poupança. |
| **Explicação** | "Explique o conceito de Liquidez Diária usando uma metáfora de um copo d'água." | O prompt criativo ajudou a simplificar um termo técnico para iniciantes. |

## 📖 Miniguia de Estudo (Entrega Final)

### 1. Resumo Estruturado
* **Mentalidade:** Investir não é sobre ficar rico rápido, mas sobre consistência e tempo (juros compostos).
* **Prioridade:** Antes de ações, foque na **Reserva de Emergência** (6 meses de custo de vida).
* **Renda Fixa:** O porto seguro. Foque em CDBs com 100% do CDI ou Tesouro Selic.

### 2. Glossário de Conceitos
* **Liquidez:** O quão rápido você consegue pegar seu dinheiro de volta.
* **CDI:** Uma taxa que caminha junto com a Selic e define quanto o banco te paga.
* **Marcação a Mercado:** A oscilação do preço dos títulos se você vender antes do prazo.

### 3. Prompts Reutilizáveis para Revisão
* *"Atue como um examinador e me faça 3 perguntas difíceis sobre os riscos do Tesouro Direto baseadas nas fontes."*
* *"Crie um roteiro de 1 minuto para eu explicar para um amigo por que a Selic alta é boa para quem investe em Renda Fixa."*
